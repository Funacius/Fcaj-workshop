# Introduction

This section explains the EduCloud Lite production-style architecture before
deploying any resource. Read it first so the later AWS steps feel connected
instead of becoming isolated console actions.

## Contents

1. [Architecture](5.1.1-architecture/)

The architecture minimizes the number of services required for a working
submission while retaining managed identity, encrypted secrets, private object
storage, HTTPS delivery, and CI/CD.
