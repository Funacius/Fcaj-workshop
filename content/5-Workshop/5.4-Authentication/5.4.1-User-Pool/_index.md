# Create a User Pool

Create a Cognito User Pool in `ap-southeast-1`:

- Sign-in option: email.
- Required attribute: email.
- Password policy: choose a policy appropriate for the workshop.
- Account recovery: self-service recovery, email only.
- MFA: optional for this submission.

Record:

```text
COGNITO_REGION
COGNITO_USER_POOL_ID
```
