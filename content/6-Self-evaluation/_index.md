# Self-Assessment

During my internship at **Amazon Web Services Vietnam Company Limited** from
**June 15, 2026** to **September 15, 2026**, I had the opportunity to apply
software engineering knowledge to a practical cloud-based application project.

My main project was **EduCloud Lite**, a cloud learning management platform that
includes course management, lesson delivery, student progress tracking, final
assessment, certificate generation, authentication, private file storage, and a
public deployment workflow on AWS.

Through this project, I improved my skills in full-stack development, backend
API design, database modeling, cloud deployment, AWS service integration,
debugging, documentation, and technical reporting. I did not communicate with
the team heavily on a daily basis, so my communication and teamwork evaluation is
based mainly on the project process, technical documentation, and ability to
follow the internship direction independently.

To reflect on the internship period objectively, I evaluate myself using the
following criteria:

## Needs Improvement

- Improve communication frequency with the team instead of relying mostly on
  independent implementation and written documentation.
- Plan evidence collection earlier, especially AWS screenshots, event photos,
  and deployment validation images.
- Add Infrastructure as Code so the AWS deployment can be recreated with less
  manual console work.
- Add automated end-to-end tests for login, course publishing, enrollment,
  assessment, certificate generation, and media loading.
- Improve production readiness with better monitoring, alarms, backup strategy,
  and cost controls.

## Overall Evaluation

Overall, I believe I completed the internship project at a good level. The
project started as a local full-stack application and was gradually improved into
a public cloud-hosted website with authentication, backend APIs, private storage,
database integration, and a structured Hugo report. The biggest improvement area
for me is not technical implementation, but communicating progress and collecting
project evidence more systematically during the process.
