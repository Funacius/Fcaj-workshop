# Tự đánh giá

Trong thời gian thực tập tại **Công ty TNHH Amazon Web Services Việt Nam** từ
**15/06/2026** đến **15/09/2026**, tôi có cơ hội áp dụng kiến thức phát triển
phần mềm vào một project cloud application thực tế.

Project chính của tôi là **EduCloud Lite**, một nền tảng quản lý học tập trên
cloud, bao gồm quản lý khóa học, bài học, tiến độ học tập, final assessment, cấp
chứng chỉ, xác thực người dùng, lưu trữ file private và quy trình triển khai
website public trên AWS.

Thông qua project này, tôi cải thiện kỹ năng full-stack development, thiết kế
backend API, mô hình hóa database, cloud deployment, tích hợp dịch vụ AWS, debug,
viết tài liệu và trình bày kỹ thuật. Tôi không giao tiếp trực tiếp với team quá
nhiều hằng ngày, nên phần đánh giá về communication và teamwork chủ yếu dựa trên
quá trình làm việc, tài liệu kỹ thuật và khả năng tự triển khai theo định hướng
thực tập.

## Nội dung cần cải thiện

- Cần giao tiếp thường xuyên hơn với team thay vì chủ yếu làm độc lập và ghi lại
  bằng tài liệu.
- Cần lên kế hoạch thu thập minh chứng sớm hơn, đặc biệt là AWS screenshots, ảnh
  sự kiện và hình ảnh kiểm thử deployment.
- Cần bổ sung Infrastructure as Code để quy trình triển khai AWS có thể tái lập
  với ít thao tác manual hơn.
- Cần thêm end-to-end tests cho login, publish course, enrollment, assessment,
  certificate generation và media loading.
- Cần cải thiện production readiness bằng monitoring, alarms, backup strategy và
  cost controls.

## Đánh giá tổng quan

Nhìn chung, tôi đánh giá bản thân đã hoàn thành project thực tập ở mức tốt.
Project bắt đầu từ một ứng dụng full-stack chạy local và được cải thiện dần
thành website public trên cloud, có authentication, backend API, private storage,
database integration và website báo cáo Hugo có cấu trúc. Điểm tôi cần cải thiện
nhiều nhất không phải là triển khai kỹ thuật, mà là giao tiếp tiến độ và thu thập
minh chứng project một cách hệ thống hơn trong suốt quá trình làm việc.
